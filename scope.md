# Security Automation Framework Scope

## Objectives
1. **Network Reconnaissance:** Build a pure Python TCP port scanner with multi-threading and banner grabbing without external binaries.
2. **Log Processing & Threat Intel Enrichment:** Automate regex IP parsing from syslog formats, filter private IP subnets, and enrich public IPs via ip-api.com and VirusTotal REST API v3.
3. **AI/ML Threat Detection:** Train supervised (Random Forest) and unsupervised (Isolation Forest) models to classify network activity as benign or malicious.
4. **CI/CD Integration:** Validate code quality and unit tests via GitHub Actions.
